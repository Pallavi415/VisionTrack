
# VisionTrack
### Real-Time Visual Attention & Gaze Behaviour Analysis

VisionTrack is a modular computer vision and machine learning
project designed to analyse facial landmarks, eye movements,
gaze behaviour and head pose through a webcam.

The system uses pretrained facial landmark models to extract
geometric features and applies custom machine learning
techniques for personalised gaze estimation.

## Objectives

- Real-time webcam frame acquisition and processing.
- Facial and iris landmark detection.
- Eye and facial geometry extraction.
- Personalised gaze estimation and calibration.
- Head-pose estimation (yaw, pitch and roll).
- Blink and eye-closure detection.
- Temporal gaze and looking-away analysis.
- Gaze heatmaps and session analytics.
- Comparison of rule-based and ML-based gaze estimation.
- Interactive 2D and 3D visualisation.

## Project Development

VisionTrack is being developed incrementally using a
modular architecture.

Each module will be implemented, tested and documented
before proceeding to the next development stage.

## Privacy

Webcam processing is intended to run locally.
No webcam footage should be uploaded or stored without
explicit user consent.

## Project Status

Currently in the environment and project setup phase.

## Important Disclaimer

Gaze direction and visual behaviour are observable signals.
They do not directly establish a person's mental attention,
understanding, interest or cognitive state.
